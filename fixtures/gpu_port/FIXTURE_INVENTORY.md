## Not distinctly generated (logged honestly)
- **near-capture**: the binding-search/capture state machine (`buildUnbound`/`stepU`/gate acceptance) is a separate 3E pathway; the unbound-search fixture (boundSeg=-1) approximates the pre-binding pivot diffusion, but a mid-flight near-capture geometry is not reconstructed here.
- **FIXED_ANCHOR Brownian/search** are athermal in practice: stepSup delegates to stepC which has no Brownian term. The fixtures are still generated and deterministic; the brownian flag is inert for that model.
