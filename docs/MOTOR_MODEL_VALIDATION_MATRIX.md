## Common-core identity (all three fixtures)

Verified identical (Gate B): converter torque law (`kconv`), F8 law (`kF8`), binding gate + kinetics
(`kbind`, `ψ_actin`), neck–lever length (`lb`), rotational drags (`γφ`, `γψ`). The nucleotide transitions,
filament reaction convention, force ordering, RNG conventions, and polarity are the shared
`TwoBodyConverterMotor` machinery — untouched by this pass (byte-identical historical `-exp4*` runs).

### `EXPLICIT_S2_L40` — frozen 4G/4H reference

material-state switch, zero direct S2 force on actin. Bit-identical to the historical `-exp4g` builder

### `CALIBRATED_S2_L40` — frozen 4I reference
Reproduces: the calibrated force curve (`k_ax = 105`, symmetric-stiff), tangent curve (median 0 % error),
conservative effective-potential work loop (~0), search RMS (7.6 nm), capture footprint (357 nm²), stroke
(6.90 nm), recoil (0.007 nm), reduced-mat recruitment (avg bound 1.73), continuity (0.82), and runtime
(~1.34 µs/step). Bit-identical to the frozen-`CAL_*` `buildBoundSup` builder (Gate D). Full reference:
`docs/TWOBODY_4G_TO_4F_CALIBRATION.md`.
